Chào bạn, dưới đây là danh sách tổng hợp tên các tác phẩm **Manga/Anime**, tên các **Tác giả (Mangaka)** và các thuật ngữ trong ngành công nghiệp truyện tranh Nhật Bản được cập nhật ở mức độ **Cực hạn (Extreme)**. Tất cả tuân thủ cấu trúc: **Từ tiếng Trung (Hán tự) = Phiên âm Hán Việt = Từ gốc (Tiếng Nhật/Anh)**.

### 3. Thuật ngữ Ngành công nghiệp (Industry Terms)
* 單行本 = Đơn Hành Bản = Tankōbon (Tập truyện lẻ)
* 連載 = Liên Tái = Serialization
* 短篇 = Đoản Biên = One-shot
* 週刊少年Jump = Chu San Thiếu Niên Jump = Weekly Shōnen Jump
* 輕小說 = Khinh Tiểu Thuyết = Light Novel
* 原作 = Nguyên Tác = Original Work
* 作畫 = Tác Họa = Art/Illustration
* 漫展 (Comiket) = Mạn Triển = Comic Market

**Quy trình & Vai trò trong ngành (Industry Roles):**
* 漫畫家 = Mạn Họa Gia = Mangaka
* 腳本 / 劇本 = Cước Bản / Kịch Bản = Script / Story
* 分鏡 = Phân Cảnh = Name / Storyboard
* 線稿 = Tuyến Cảo = Line Art
* 背景 = Bối Cảnh = Backgrounds
* 網點 = Võng Điểm = Screentones
* 助手 = Trợ Thủ = Assistant
* 責任編輯 = Trách Nhiệm Biên Tập = Managing Editor
* 總編輯 = Tổng Biên Tập = Editor-in-Chief
* 番外編 = Phiên Ngoại Biên = Side Story / Omake

**Các Nhà xuất bản lớn (Major Publishers):**
* 集英社 = Tập Anh Xã = Shueisha (Weekly Shonen Jump)
* 講談社 = Giảng Đàm Xã = Kodansha (Weekly Shonen Magazine)
* 小學館 = Tiểu Học Quán = Shogakukan (Weekly Shonen Sunday)
* 角川書店 = Giác Xuyên Thư Điếm = Kadokawa Shoten
* 秋田書店 = Thu Điền Thư Điếm = Akita Shoten
* 史克威爾艾尼克斯 = Sử Khắc Uy Nhĩ Ngải Ni Khắc Tư = Square Enix (Gangan)
* 芳文社 = Phương Văn Xã = Houbunsha
* 白泉社 = Bạch Tuyên Xã = Hakusensha (Young Animal / LaLa)
* 青文 = Thanh Văn = Ching Win
* 東立 = Đông Lập = Tong Li
