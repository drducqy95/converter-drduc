# Già Thiên (遮天)

**Tác giả:** 辰東 = Thần Đông

**Bối cảnh:** 
北斗星域 = Bắc Đẩu Tinh Vực
紫微星域 = Tử Vi Tinh Vực
地球 = Địa Cầu
仙路 = Tiên Lộ
生命禁區 = Sinh Mệnh Cấm Khu

---

### Hệ thống tu luyện + Cấp bậc tương ứng (Ngũ Đại Bí Cảnh)

**1. Luân Hải Bí Cảnh (轮海秘境 - Luân hồi hải):**
* 苦海 = Khổ Hải
* 命泉 = Mệnh Tuyền
* 神橋 = Thần Kiều
* 彼岸 = Bi Ngạn

**2. Đạo Cung Bí Cảnh (道宫秘境):**
* Tâm, Can, Tì, Phế, Thận (Ngũ thần tàng)

**3. Tứ Cực Bí Cảnh (四极秘境):**
* Tứ chi (Tu luyện tứ chi để thông thiên triệt địa)

**4. Hóa Long Bí Cảnh (化龙秘境):**
* Tủy sống (Hóa long cửu biến, tích tụ sức mạnh rồng)

**5. Tiên Đài Bí Cảnh (仙台秘境):**
* 仙台一 = Tiên Đài 1 = Bán bộ đại năng
* 仙台二 = Tiên Đài 2 = Đại năng (Thánh địa chi chủ)
* 仙台三 = Tiên Đài 3 = Vương giả
* 聖人 = Thánh Nhân
* 聖人王 = Thánh Nhân Vương
* 大聖 = Đại Thánh
* 準帝 = Chuẩn Đế
* 大帝 = Đại Đế
* 紅塵仙 = Hồng Trần Tiên (Bất tử tại nhân gian)

### Tổ chức, thế lực, chức vụ

**Chức vụ:**

### Sơ đồ quan hệ nhân vật

* Diệp Phàm (Thú cưng/Cố vấn) -> Hắc Hoàng
* Diệp Phàm (Ân sư/Thần vương) -> Khương Thái Hư

### Cửu Bí
* 九秘 = Cửu Bí
1. 臨 = Lâm (Tâm cảnh vô địch)
2. 兵 = Binh (Thao túng binh khí)
3. 斗 = Đấu (Chiến đấu công phạt đệ nhất)

8. 前 = Tiền (Dự báo tương lai)
