# Đấu Phá Thương Khung (斗破苍穹)

**Tác giả:** 天蠶土豆 = Thiên Tàm Thổ Đậu

**Bối cảnh:** 
斗氣大陸 = Đấu Khí Đại Lục
中州 = Trung Châu
魔獸山脈 = Ma Thú Sơn Mạch
大戈壁 = Đại Qua Bích

---

### Hệ thống tu luyện + Cấp bậc tương ứng

**1. Cấp bậc Đấu Khí:**
* 斗之氣 = Đấu Chi Khí (1-9 đoạn)
* 斗者 = Đấu Giả (1-9 tinh)
* 斗師 = Đấu Sư
* 大斗師 = Đại Đấu Sư
* 斗靈 = Đấu Linh
* 斗王 = Đấu Vương
* 斗皇 = Đấu Hoàng
* 斗宗 = Đấu Tông
* 斗尊 = Đấu Tôn (Tiền kỳ, Trung kỳ, Hậu kỳ, Đỉnh phong 1-9 chuyển)
* 半聖 = Bán Thánh
* 斗聖 = Đấu Thánh (1-9 tinh)
* 斗帝 = Đấu Đế

**2. Phẩm cấp Luyện Dược Sư:**
* 一品 ~ 九品 = Nhất Phẩm ~ Cửu Phẩm
* 帝品 = Đế Phẩm

**3. Phẩm cấp Linh hồn:**
* 凡境 = Phàm Cảnh
* 靈境 = Linh Cảnh
* 天境 = Thiên Cảnh
* 帝境 = Đế Cảnh
